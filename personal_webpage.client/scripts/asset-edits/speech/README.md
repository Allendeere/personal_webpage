# Speech-game presentation assets

Sarah requested subtle styling changes limited to this project, keeping the existing interface structure. The 13 numbered WebP files are the reviewed presentation derivatives used by `prepare-assets.mjs`. They correspond to the same manifest order and original dimensions.

Built-in imagegen refined ten scene/composite images. Original question/dialogue overlays and the composite statistics window were restored where needed to preserve the supplied information. For images 10–12, only blank cream surfaces receive a very light generated paper texture; text, chart shapes, values, icons, and controls stay in their original positions. No functionality was added or changed. The original Downloads files remain unchanged.

Exact prompts and mode are in `../prompts.json`. Store reviewed changes here as well as in public assets so a future import does not restore the previous presentation.
